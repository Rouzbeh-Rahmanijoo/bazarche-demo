مستندات قالب فروشگاهی «بازارچه»

قالب HTML/CSS/JS راست‌چین و ریسپانسیو — نسخه ۱٫۰

۱. معرفی

«بازارچه» یک قالب فروشگاهی کاملاً فارسی و راست‌چین (RTL) است که با HTML5، CSS3 و جاوااسکریپت خالص ساخته شده و به هیچ فریمورک یا کتابخانه خارجی نیاز ندارد. فونت وزیرمتن همراه قالب است و بدون اینترنت هم درست نمایش داده می‌شود.

  • صفحات: صفحه اصلی، فروشگاه (لیست محصولات با فیلتر)، صفحه محصول، سبد خرید
  • سازگار با موبایل، تبلت و دسکتاپ
  • اسلایدر، شمارنده معکوس تخفیف، سبد خرید دمو (localStorage)، کد تخفیف نمونه
  • ارقام و قیمت‌ها به‌صورت فارسی با جداکننده هزارگان

۲. ساختار فایل‌ها

shop-template/
├── index.html        صفحه اصلی
├── shop.html         لیست محصولات
├── product.html      صفحه محصول
├── cart.html         سبد خرید
├── docs/index.html   همین راهنما
└── assets/
    ├── css/style.css
    ├── js/main.js       منطق قالب
    ├── js/products.js   داده نمونه محصولات
    ├── fonts/           فونت وزیرمتن + مجوز OFL
    └── img/             تصاویر نمونه (SVG)

۳. تغییر رنگ‌ها

تمام رنگ‌های قالب در ابتدای فایل assets/css/style.css داخل بلوک :root تعریف شده‌اند. با تغییر چند خط، ظاهر کل سایت عوض می‌شود:

:root {
  --brand: #0f766e;   /* رنگ اصلی */
  --accent: #f59e0b;  /* رنگ تأکیدی (دکمه‌های مهم) */
  --danger: #e11d48;  /* تخفیف و حذف */
  --ink: #0f172a;     /* رنگ عنوان‌ها */
}

۴. لوگو، متن‌ها و اطلاعات تماس

لوگو در هدر هر صفحه با کلاس .logo قرار دارد. برای استفاده از تصویر، تگ <span class="logo-mark"> را با <img src="assets/img/logo.svg"> عوض کنید. اطلاعات تماس، آدرس و نمادهای اعتماد در بخش <footer> قرار دارند.

۵. افزودن و ویرایش محصول

هر محصول یک بلوک <article class="card"> است؛ برای افزودن محصول جدید یکی از کارت‌ها را کپی کنید و عنوان، قیمت و تصویر را عوض کنید. برای اینکه دکمه «افزودن به سبد» درست کار کند، دو مورد را هماهنگ کنید:

  • مقدار data-id روی دکمه
  • یک ردیف با همان id در assets/js/products.js (عنوان، قیمت، قیمت قبل از تخفیف و نام فایل تصویر)

تصاویر پیش‌فرض، SVG نمونه هستند؛ آن‌ها را با عکس واقعی (ترجیحاً WebP با نسبت ۱:۱) جایگزین کنید.

۶. تنظیمات سبد خرید

در ابتدای assets/js/main.js این مقادیر قابل تغییرند:

var FREE_SHIPPING_FROM = 2000000; // حداقل مبلغ ارسال رایگان
var SHIPPING_COST = 45000;        // هزینه ارسال
var COUPONS = { WELCOME: 10, BAHAR: 15 }; // کدهای تخفیف نمونه (درصد)

توجه: سبد خرید این قالب فقط نمایشی است و داده‌ها در مرورگر کاربر ذخیره می‌شود. برای فروشگاه واقعی باید قالب را به سیستم فروشگاه‌ساز (وردپرس/ووکامرس، لاراول و...) یا بک‌اند خودتان متصل کنید. دکمه «ادامه و تسویه حساب» عمداً به جایی وصل نشده است.

۷. فونت

فونت «وزیرمتن» (Vazirmatn) به‌صورت فایل متغیر (woff2) در assets/fonts قرار دارد و با مجوز SIL Open Font License منتشر شده است؛ متن مجوز در همان پوشه است. برای تغییر فونت، @font-face ابتدای فایل CSS و مقدار font-family روی body را عوض کنید.
